Model options require the matching Foundry deployment settings in .env. Document Translator LLM is a public-preview feature. Layout fidelity is not automatically assessed. Local retrieval uses lightweight lexical matching, not Azure AI Search.

Runs real, billable Azure calls using your local Azure identity. Files and reports remain on this machine; document data is sent to the configured Azure AI services.

Scope & limitations

PowerPoint text is replaced in existing shapes and tables. Text found inside pictures is translated in the companion TXT, not on the slide. PDFs and standalone images use overlays, so fonts and backgrounds may differ. Layout fidelity requires manual review. Charts are not supported.

PDF terms are checked, not applied as a Translator glossary. Review scores are experimental; a pass is not certification.

DOCX keeps tables, headers, footers, and images; native text is translated. Image text and comments remain unchanged. Accept tracked changes and convert dynamic fields to text before uploading. Inline styling and pagination may change.

XLSX translates text cells, including hidden sheets. Formulas, numbers, dates, sheet names, chart text and image text remain unchanged. Text-dependent formulas and text fit need manual review. XLS and macro-enabled workbooks are unsupported.
